# Map province labels as MapLibre symbol layers

**Status:** accepted  
**Date:** 2026-11-21  
**Context:** Province names and strength counters were HTML `maplibregl.Marker` elements. The map hid the real WebGL canvas (`opacity: 0`) and copied frames into a 2D overlay via `readPixels`, so labels lagged behind pans and zooms at high DPR.  
**Decision:** Show the native MapLibre canvas, drop the per-frame blit, and render province names, victory stars, depot marks, and strength counters in `province-labels` / `province-counters` symbol layers. Self-host glyph PBFs under `public/fonts/` (Noto Serif for provinces, Open Sans for backdrop). Counter pills use `map.addImage` with `icon-text-fit`. Label zoom fade is a `text-opacity` expression using `PROVINCE_LABEL_HIDDEN_ZOOM` → `PROVINCE_LABEL_FULL_ZOOM`.  
**Consequences:** Markers and `.map-tag` CSS are no longer on the hot path (SVG fallback still paints labels in SVG). Headless screenshots no longer depend on `preserveDrawingBuffer` for the blit. Map verify scripts query `province-labels` instead of `.map-tag`. Changing label typography requires font PBF updates, not React marker code. Target painting (`lib/map/province-paint.ts`) lightens only neighbour move/attack/reach provinces from each province’s own fill; non-targets stay at base fill (no navy dim overlay).
