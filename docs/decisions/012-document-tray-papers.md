# Floating papers use a document tray, not HUD toggles

**Status:** accepted  
**Date:** 2026-11-23  
**Context:** Phase 2D Parts 5–6 put Orders / Lesson / Province / Legend (and campaign Log, Chief of Staff, OHL) in parchment `FloatingWindow`s toggled from the HUD. Raymond’s Part 7 brief asked for documents-on-a-table UX: press–drag–release without a second click to drop, no vertical grow while dragging Orders, and a bottom tray where stowed papers sit as tabs. Follow-up feedback required **drag-first** filing (no per-paper Stow buttons / click-to-toggle), a clear tray drop highlight, tuck-into-tab motion, drag-a-tab-out (with Enter/Escape for keyboard), header-only Y clamp so papers can reach the tray, and width/last-size retention on restore.  
**Decision:** Remove window-open buttons from the top bar (title, date, and lesson/campaign goal stay). Host a parchment **document tray** (`components/document-tray.tsx`, `lib/ui/document-tray.ts`) along the bottom of the map stage. Stowed papers are tray tabs (real `<button>`s). **Drag a paper down onto the tray** to file it (tray shows `data-drop-active` highlight; paper sets `data-over-tray` and visually tucks). The drop hit covers the **whole bottom bar**, anything below it, and a release with `clientY` at or past the viewport bottom; a paper whose header already overlaps the tray also files — including short papers like Orders from OHL. **Drag a tab up onto the map** (or **Enter** on a focused tab) to take it out at the release / soft restore point, keeping prior `width`/`height`. **Escape** files the topmost open paper. No visible Stow / show-hide controls. `FloatingWindow` uses pointer capture (`pointerup` / `pointercancel` / `lostpointercapture`) for press–drag–release, locks height while dragging (optional resize handle), and clamps Y so the header grip **never goes under the tray** while dragging or at rest. Papers use z above `DOCUMENT_TRAY_Z` (40) so they never paint behind the tray. SessionStorage keeps open/xy/z/width/height for the tab (`ostfront-windows-v1:campaign|teach`). Below `lg`, the tray is a bottom tab strip that swaps the stacked panel; `/teach` keeps Lesson (and Resolve) pinned so 390×844 QA stays green.  
**Consequences:** Demo-check and FEATURES treat `[data-testid=document-tray]` as the file/restore surface (drag + keyboard), not HUD toggles or Stow buttons. Engine, AI, API, and rules code are untouched. ADR 010/011 chrome and Lesson Resolve guarantees remain; this ADR only changes how papers are summoned and put away.
