# Teaching drill uses the general’s-table shell

**Status:** accepted  
**Date:** 2026-11-22  
**Context:** ADR 010 put the campaign on a map-first floating-window layout at `lg+` but left `/teach` on a three-column dock. Phase 2D Part 6 asked for the same parchment table on the tutorial, with low-text prompts and persistent lesson target highlights, without changing lesson resolve logic or trust boundaries.  
**Decision:** Reuse `FloatingWindow`, HUD parchment chrome, and `useDesktopShell` on `/teach`. Desktop windows are Lesson, Orders, Province, and Legend (`lib/ui/teach-windows.ts`) — not Log / Chief of Staff / OHL. Default placement stacks Lesson (top) and a compact Legend (directly under it) in the left column so Kraków/Kielce/Lublin stay clear; Orders sits top-right. Height caps budget the left stack so Lesson and Legend do not overlap. Lesson uses `bodyScroll={false}` so Resolve stays pinned in the panel footer. Escape closes the topmost teach window, then clears selection. HUD shows the lesson title (`teach-goal`) instead of the campaign objective and omits campaign scoring. Resolve lives only in the Lesson panel (prediction-gated). Lesson copy is a short map-first prompt; longer briefing and pedagogy sit behind expandable controls. MapLibre adds brass lesson-focus layers: solid target outline + thinner dashed source outlines (`lib/map/lesson-highlight.ts`), pulsing only when motion is allowed. Below `lg`, keep the stacked map → Lesson → Orders/Province tabs.  
**Consequences:** Demo-check and FEATURES treat `/teach` desktop as a general’s table with `data-lesson-highlights`, a single `teach-resolve`, left-column Legend under Lesson, and non-overlapping Lesson/Orders/Legend windows. Campaign window ids stay separate from teach ids. Shared `--primary` / `--brass-deep` darken slightly so parchment text contrast clears WCAG AA; map faction paints are unchanged.
